## [0.6.0] - 2026-10-23

Этап 6: авто-разбор гонки.

### Добавлено

- Отчёт о гонке по шаблону Jinja2 (`python -m f1lab.report --season --round`): итог, позиции,
  пит-стопы и шины, нейтрализации и отдельный «взгляд симулятора» (фаворит, точность против решётки,
  неожиданные финиши, стратегии поля, которые подошли бы призёрам лучше). Экспорт в Markdown, рядом
  графики PNG: стинты всего поля с периодами SC/VSC/красного флага и прогноз против факта.
- Факты собраны в `RaceFacts`, шаблон только форматирует их поля; тест проверяет, что каждое число в
  тексте взято из фактов. Мокрые гонки получают отчёт без симуляции с объяснением причины.
- API: `GET /api/races/{race_id}/report` — тот же Markdown, имя файла и признак симуляции.
- Дашборд: раздел «Отчёты» с оглавлением, скачиванием `.md`, копированием и графиком прогноза против
  факта; страница грузится лениво, Markdown-рендерер не попадает в основной бандл.
- Примеры отчётов за 2025 год в `docs/reports` (Австралия, Бахрейн, Саудовская Аравия, Канада).
- Цвета промежуточной и дождевой резины на графиках matplotlib.

### Исправлено

- Проезд по пит-лейну за сейфти-каром («SAFETY CAR THROUGH THE PIT LANE») больше не считается
  пит-стопом ни в стратегиях симулятора, ни в отчёте. Раньше Jolpica и OpenF1 давали лишние остановки
  всему полю (Австрия и Сан-Паулу 2023, Катар 2024, Австралия и Канада 2025). Бэктест 2025:
  Spearman 0,763 → 0,776, MAE 2,48 → 2,42; Канада-2025: Spearman 0,43 → 0,71.

### Изменено

- Круг лидера в момент события считает одна общая функция `leader_lap` (калибровка и отчёт).
- На графике бэктеста только целые позиции на оси; заголовок задаётся параметром.
- README: раздел об авто-разборе, запуск CLI, новый эндпоинт, скриншоты; сайт: этап 6 отмечен готовым.

## [0.5.0] - 2026-10-22

Этап 5: дашборд.

### Добавлено

- API на FastAPI (`uvicorn f1lab.api.main:app`): гонки, симуляция гонки, сравнение стратегий,
  чувствительность к Safety Car, модели шин по трассам. Калибровка выполняется один раз при первом
  запросе, результаты кэшируются (seed фиксирован); ошибки 404/422 с понятным текстом.
- Симулятор для дашборда: гистограммы финишных позиций (со сходами), доля гонок с SC/VSC,
  масштабирование частоты нейтрализаций, оценка одной гонки по готовой сводке.
- Дашборд: разделы «Гонки» (прогноз против факта, точность против решётки), «Шины» (кривые
  деградации с фактическими кругами, сравнение трасс), «Стратегии» (фактическая против двух своих,
  распределение финиша, чувствительность к SC); главная показывает живой расчёт.
- Графики — свои SVG-компоненты на d3-scale и d3-shape: подсказки по наведению и с клавиатуры,
  табличный вид у каждого графика, форма маркера как второй канал рядом с цветом; палитра серий
  проверена валидатором (различима при дальтонизме).
- Веб-тесты на записанных ответах API и контрактный тест, который сверяет эти фикстуры со схемами.

### Изменено

- Тестовый клиент FastAPI работает через httpx2, как рекомендует Starlette.
- README: запуск API и дашборда, эндпоинты, скриншоты; сайт: этап 5 отмечен готовым.

## [0.4.0] - 2026-10-22

Этап 4: симулятор гонки.

### Добавлено

- Таблица `qualifying` (позиция, Q1–Q3) и её загрузка из Jolpica; схема версии 2 с миграцией на месте:
  старые базы обновляются сами, без перезагрузки данных.
- Стратегии: нотация `S3-15-H-38-M`, проверка правил (два сухих состава, пит-стопы внутри дистанции),
  восстановление реальных стратегий из стинтов; смена шин под красным флагом бесплатна.
- Калибровка по 2023–2024: темп по позиции в квалификации и «форма дня», потеря на старте, потери на
  пит-стопе относительно поля (и скидка под SC/VSC), частота и длина SC/VSC по трассам, сходы.
- Векторный движок Монте-Карло (5000 гонок за доли секунды): всё поле, грязный воздух, порог обгона,
  пит-стопы, SC/VSC с рестартом, сходы; общие случайные числа для честного сравнения стратегий.
- Сводки с доверительными интервалами: средняя позиция, P(победа), P(подиум), P(очки), P(сход),
  позиция при условии финиша; сравнение стратегий с парной разницей.
- Бэктест на 2025 (вне выборки) против базовой модели «финиш = решётка»: MAE 2,48 против 2,77
  позиции; подбор параметров обгона на 2023–2024 в заранее заданных правдоподобных диапазонах.
- CLI `python -m f1lab.sim race | compare | backtest | race-craft`, графики, отчёты в `docs/sim`.
- `docs/assumptions.md`: все упрощения симулятора с числами и источниками.

### Изменено

- Общий стиль графиков, Markdown-таблицы и консольный вывод вынесены в `f1lab.plotting`,
  `f1lab.markdown`, `f1lab.console`.
- README: исправлен порядок разделов (особенности источников снова в «Данных»).
- Сайт: этап 4 отмечен готовым.

## [0.3.0] - 2026-10-21

Этап 3: модель шин.

### Добавлено

- `sql/model_laps.sql` и `f1lab.models.laps`: круги с составом, возрастом шины и флагами пит-стопов;
  круг пит-стопа в двух стинтах относится к старому стинту.
- Восстановление периодов SC, VSC и красного флага по сообщениям race control (на 2023–2025 ровно
  46 SC, 32 VSC, 11 красных флагов).
- Фильтр «чистых» кругов с причиной исключения для каждого круга (79,5% кругов чистые).
- Модель деградации: OLS на трассу с уровнем пилота в гонке, топливом, сдвигом и износом по составам,
  95% интервалы; отказ от подгонки, если топливо и износ неразделимы.
- Сжатие наклонов к общему наклону состава (эмпирический Байес, DerSimonian–Laird) с перестройкой
  трассы при зафиксированных наклонах; ограничение экстраполяции износа максимальным возрастом шины.
- Оценка на отложенном 2025 году с абляцией: MAE 0,785 (средний круг) → 0,560 (без деградации) →
  0,545 (по трассе) → 0,514 с (итоговая модель); лучше варианта без деградации на 17 трассах из 24.
- Команда `python -m f1lab.models`: графики в стиле сайта, `degradation_params.csv`, `results.md`.
- Документ модели `docs/models/tyre_model.md`: метод, допущения, разбор ошибок, варианты улучшения.
- Проверка качества `incomplete_lap_coverage`: находит дыру OpenF1 в Майами-2025.
- Зависимости pandas, NumPy, SciPy, statsmodels, matplotlib.

### Изменено

- Сайт: этап 3 отмечен готовым.

## [0.2.0] - 2026-10-21

Этап 2: загрузка данных.

### Добавлено

- Схема SQLite на SQLAlchemy Core: `races`, `drivers`, `results`, `pit_stops`, `laps`, `stints`,
  `weather`, `race_control` и служебные `ingest_runs`, `schema_meta` (версия схемы).
- HTTP-клиент с кэшем на диске, паузой между запросами и повторами (429, 5xx, обрывы).
- Клиенты Jolpica-F1 (расписание, результаты, пит-стопы, пагинация) и OpenF1 (сессии, круги,
  стинты, погода, race control).
- Чистые трансформации ответов API в строки таблиц; сопоставление гонок Jolpica и сессий OpenF1
  по дате с допуском ±1 день; номера машин переводятся в `driverId` через протокол гонки.
- Идемпотентный загрузчик: гонка заменяется целиком в одной транзакции, уже загруженные
  пропускаются без `--force`. CLI `python -m f1lab.ingest`.
- 9 проверок качества данных на SQL (`sql/data_quality.sql`), CLI `python -m f1lab.db.quality`.
  Отделяют ошибки от особенностей OpenF1: неучтённый круг после финиша, стинты из нуля кругов,
  круг пит-стопа в двух стинтах. На полной базе 2023–2025 (70 гонок) все проверки проходят.
- Пример аналитики: `sql/tyre_pace_by_compound.sql`.
- Записанные реальные ответы API в `tests/fixtures` (Бахрейн-2024 и Сан-Паулу-2024) и скрипт
  их обновления; опциональные live-тесты `pytest -m network`.

### Исправлено

- Пит-стопы с пустой длительностью в Jolpica (Британия-2024, Австрия-2025) больше не роняют
  загрузку гонки: длительность сохраняется как `NULL`.

### Изменено

- Источник кругов, шин и погоды: OpenF1 вместо FastF1 (архив тайминга F1 отвечает 403 из сети
  автора). Данные доступны с сезона 2023.
- Сайт: этап 2 отмечен готовым, источники данных обновлены.

## [0.1.0] - 2026-10-20

Этап 1: каркас.

  иллюстрация стратегии, дорожная карта этапов.
- GitHub Actions: проверки Python и web на ubuntu и windows.
- `CLAUDE.md`, `LICENSE` (MIT), `README.md`, этот `CHANGELOG.md`.

- Стек в `CLAUDE.md`: pip + requirements вместо uv; дашборд на React + FastAPI вместо Streamlit.
