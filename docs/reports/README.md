# Примеры авто-разборов гонок

Отчёты собраны командой `python -m f1lab.report --season 2025 --round N` из базы, загруженной по
README, вручную не редактировались. Каждый — Markdown и графики PNG рядом с ним.

| Гонка | Чем интересна |
|---|---|
| [Australian Grand Prix 2025](2025-01-albert_park.md) | мокрая гонка: три сейфти-кара, симулятор её не считает; проезды по пит-лейну за SC не считаются пит-стопами |
| [Bahrain Grand Prix 2025](2025-04-bahrain.md) | сухая, вне выборки калибровки: прогноз симулятора, неожиданности и идеи по стратегиям призёров |
| [Saudi Arabian Grand Prix 2025](2025-05-jeddah.md) | сухая, одна остановка у 17 из 18 финишёров, симулятор точен (Spearman 0,95) |
| [Canadian Grand Prix 2025](2025-10-villeneuve.md) | финиш за сейфти-каром через пит-лейн: 49 записанных «пит-стопов» без смены шин |

Как устроен отчёт и откуда каждое число, описано в [README](../../README.md#авто-разбор-гонки).
